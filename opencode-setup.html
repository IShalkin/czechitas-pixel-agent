OpenCode
+ OpenRouter

Nainstaluj si doma, ať na workshopu nemusíme řešit instalaci.

Tenhle návod tě provede instalací OpenCode (AI coding agent v terminálu) a propojením s OpenRouter (jeden účet, stovky AI modelů). Trvá to ~15 minut.

👉 Předpokládá: už máš hotové prerekvizity od Kuby — Python 3.10+, OpenRouter účet a API klíč. Pokud ne, dodělej nejdřív Kubův návod.

1. Nainstaluj OpenCode

Vyber svůj operační systém:

Otevři Terminal (najdeš v Spotlight: ⌘ + Space → napiš terminal).

Doporučeno: Homebrew

Pokud ještě nemáš Homebrew, nejdřív ho nainstaluj (jednorázově):

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Po instalaci ti Homebrew může napsat dvě "Next steps" hlášky s příkazy začínajícími echo … a eval … — spusť je, jinak brew nebude fungovat.

Pak nainstaluj OpenCode:

brew install anomalyco/tap/opencode

Alternativa: instalační skript (curl)

Pokud Homebrew nechceš, jeden řádek to vyřeší:

curl -fsSL https://opencode.ai/install | bash

Skript stáhne binárku a uloží ji do ~/.opencode/bin/opencode a přidá tuto cestu do PATH (přes ~/.zshrc nebo ~/.bashrc). Po instalaci zavři terminál a otevři nový, aby se PATH načetl.

Alternativa: npm (potřebuješ Node.js 18+)

npm install -g opencode-ai@latest

Apple Silicon (M1/M2/M3) vs Intel

Všechny tři způsoby výše fungují na obou. Homebrew sám pozná, jaký máš procesor a stáhne správnou variantu.

Ověř, že to funguje

opencode --version

Měla bys vidět něco jako opencode 0.x.x. Pokud terminál říká command not found: opencode, viz FAQ → command not found (Mac).

Stiskni Win + X → vyber "Terminal" nebo "PowerShell". Použij ten obyčejný (ne Admin), pokud návod neřekne jinak.

Pozor: nepoužívej Command Prompt (cmd.exe) — některé příkazy níže fungují jen v PowerShellu.

Doporučeno: Scoop

1) Nainstaluj Scoop (pokud ho ještě nemáš):

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
irm get.scoop.sh | iex

Pokud první řádek hodí dotaz "Do you want to change the execution policy?" — odpověz Y.

2) Nainstaluj OpenCode:

scoop install opencode

Alternativa 1: winget (předinstalovaný na Win 10/11)

Winget máš v moderních Windows už nainstalovaný:

winget install anomalyco.opencode

Pokud winget hlásí, že balíček nezná, použij Scoop výše.

Alternativa 2: Chocolatey

Pokud máš Chocolatey, spusť PowerShell jako administrátor (pravým kliknutím → Run as administrator):

choco install opencode -y

Alternativa 3: npm (potřebuješ Node.js 18+)

Pokud nic z výše uvedeného nefunguje, nainstaluj Node.js LTS a pak:

npm install -g opencode-ai@latest

Ověř, že to funguje

opencode --version

Měla bys vidět něco jako opencode 0.x.x. Pokud PowerShell říká, že opencode nezná, zavři ho a otevři nové okno (PATH se musí načíst). Pokud to po restartu okna nepomohlo, viz FAQ → command not found (Windows).

Antivirus / Defender: občas u scoop nebo npm instalace nahlásí false-positive (typicky "Trojan:Script/Wacatac"). Pokud Defender soubor zablokuje, klikni Allow a přidej výjimku ke složce %USERPROFILE%\scoop (Scoop) nebo %APPDATA%\npm (npm).

2. Připoj OpenRouter

Před prvním spuštěním přihlas svůj OpenRouter klíč přímo z terminálu/PowerShellu (jednorázově):

opencode auth login
  1. Šipkami nahoru/dolů vyber ze seznamu OpenRouter a stiskni Enter.
  2. OpenCode tě požádá o API klíč. Vlož ten, který už máš z openrouter.ai/keys (z Kubova návodu) a potvrď Enter.
  3. Klíč se uloží lokálně do ~/.local/share/opencode/auth.json (Mac/Linux) nebo %USERPROFILE%\AppData\Local\opencode\auth.json (Windows). Nikdy ho neposílej dál — chová se jako heslo.

Ověř, že přihlášení proběhlo:

opencode auth list

Měla bys vidět openrouter v seznamu.

Alternativně můžeš přihlášení udělat uvnitř rozhraní OpenCode přes příkaz /connect. Výsledek je stejný — vyber si ten způsob, který ti přijde přirozenější.

3. Spusť OpenCode poprvé

Vytvoř si testovací složku a otevři v ní OpenCode:

# macOS / Linux
mkdir opencode-test
cd opencode-test
opencode
# Windows PowerShell
mkdir opencode-test
cd opencode-test
opencode

Otevře se barevné rozhraní (TUI) v terminálu. Pokud jsi přeskočila krok 2, OpenCode tě teď donutí připojit providera.

Klávesy uvnitř OpenCode:
  • Tab — přepínání mezi build (full-access) a plan (read-only) agentem
  • Ctrl + C (2×) nebo /exit — zavřít OpenCode
  • /help — zobrazit všechny příkazy

Vyber model

Uvnitř OpenCode napiš:

/models

Otevře se seznam dostupných modelů. Konkrétní model pro workshop ti řekne Kuba na začátku — pro teď stačí, že seznam vidíš a můžeš si v něm libovolný model vybrat.

Tip: OpenRouter má i bezplatné modely (najdeš je v seznamu jako :free). Pro setup a smoke test úplně stačí.

4. Smoke test 🚦

Pořád v OpenCode (po /connect a /models), do hlavního chatu napiš:

Napiš krátký Python skript, který spočítá kolik je 2+2 a vypíše výsledek.

Pokud OpenCode:

✅ Vytvořil main.py a navrhl ti ho spustit — všechno funguje. Hotovo, můžeš zavřít okno.
❌ Hodil chybu — typicky 401 Unauthorized (špatný klíč, znovu opencode auth login) nebo 402 / insufficient credits (vybraný model není free, vyber jiný přes /models). Detaily v FAQ.

FAQ — nejčastější problémy

macOS: terminál říká command not found: opencode

PATH nezná cestu k binárce. Tři kroky v pořadí:

  1. Zavři terminál a otevři nový. 90 % případů to vyřeší.
  2. Pokud ne, zkontroluj kde binárka je: 
    ls -la ~/.opencode/bin/opencode /opt/homebrew/bin/opencode /usr/local/bin/opencode 2>/dev/null
    Aspoň jedna z těch cest by měla existovat.
  3. Přidej cestu ručně do shellu (zsh = default na moderních Macích): 
    echo 'export PATH="$HOME/.opencode/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

Windows: PowerShell říká opencode : The term … is not recognized

Stejný problém — PATH ještě neví, kde binárka leží. Postup:

  1. Zavři PowerShell, otevři nové okno.
  2. Pokud i tak nezná, najdi binárku: 
    Get-ChildItem -Path $env:USERPROFILE -Filter opencode.exe -Recurse -ErrorAction SilentlyContinue | Select-Object FullName
  3. Když najdeš cestu (např. C:\Users\Tvé Jméno\scoop\apps\opencode\current\opencode.exe), přidej její složku do uživatelské PATH:

    Win+R → sysdm.cpl → Advanced → Environment Variables → User variables → vyber Path → Edit → New → vlož cestu (BEZ opencode.exe na konci) → OK ×3 → restart PowerShellu.

Windows: scoop : The term 'scoop' is not recognized

Po instalaci Scoopu je potřeba zavřít a znovu otevřít PowerShell. Pokud ani potom Scoop nefunguje, pravděpodobně se neinstaloval — spusť instalační příkaz znovu a všimni si chybové hlášky.

Windows: PowerShell hlásí running scripts is disabled

Spusť toto a odpověz Y:

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Windows: Defender / antivirus zablokoval instalaci

OpenCode binárka občas spustí false-positive (nejčastěji "Trojan:Script/Wacatac.B!ml"). Postup:

  1. Otevři Windows Security → Virus & threat protection → Protection history
  2. Najdi blokovaný soubor → Actions → Allow
  3. Pokud chceš preventivně: Manage settings → Add or remove exclusions → Add an exclusion → Folder → vyber %USERPROFILE%\scoop

macOS: "opencode" cannot be opened because the developer cannot be verified

Gatekeeper. Otevři System Settings → Privacy & Security, scrolluj dolů, klikni "Open Anyway" u zablokovaného souboru. Pokud to dělá u OpenCode binárky stažené přes curl, alternativně:

xattr -d com.apple.quarantine ~/.opencode/bin/opencode

Při přihlášení: 401 Unauthorized nebo Invalid API key

  • Zkontroluj, že máš správný klíč z openrouter.ai/keys (začíná na sk-or-v1-…)
  • Klíč musí mít aspoň jednu povolenou kategorii v OpenRouter dashboardu
  • Zkus znovu: opencode auth logout → opencode auth login

Při chatování: 402 Payment required nebo insufficient credits

Vybraný model není free. Otevři /models a vyber model označený :free — nebo se zeptej Kuby, který model na workshopu používáme.

Při chatování: 429 Too Many Requests

Hit rate limit free tieru. Počkej minutu a zkus znovu.

Při chatování: This model is not available / model error

OpenRouter dynamicky nabízí různé modely. Pokud zrovna není dostupný, otevři /models v OpenCode a vyber jiný free model.

Doma jsem za firemním proxy / VPN / Zscalerem

Pokud instalace selhává s chybou typu self-signed certificate in certificate chain nebo SSL: CERTIFICATE_VERIFY_FAILED, jsi pravděpodobně za firmemním firewallem.

Doporučení: na workshop přijď z osobního počítače, ne pracovního. Setup za korporátní sítí ti sebere víc času, než celý workshop.

Pokud osobní počítač nemáš, zkus mobilní hotspot — instalace většinou potřebuje internet jen jednou.

Mám Windows 7 / 8 / Windows na ARM

Win 7/8 oficiálně nepodporujeme — nainstaluj si Win 10/11 (zdarma upgrade) nebo přijď s Macem. Windows na ARM (Surface Pro X) by měl fungovat, ale není testovaný.

Mám starý Mac (Intel, 10.14 nebo starší)

OpenCode potřebuje macOS 11+ (Big Sur). Starší verze updatuj, nebo pokud nejde, OpenCode prostě nepoběží.

Mám Linux

Funguje. Použij curl instalátor nebo (Arch) sudo pacman -S opencode. Pokud máš Ubuntu/Debian, nejjednodušší je curl.

Musím dobíjet kredit na OpenRouter?

Ne — pro workshop budeme používat free modely (registrace přes Google/GitHub stačí, žádná karta). Free tier má rate limity, ale na workshop bohatě vystačí.

Můžu místo OpenCode použít Claude Code / Cursor / GitHub Copilot?

Pro samotný workshop je OpenCode doporučená volba (open-source, kompatibilní s OpenRouter). Skills, které postavíme (~/.claude/skills/), čte taky Claude Code i GitHub Copilot — takže to, co si odneseš domů, ti bude fungovat i jinde. Ale na workshop přijď s OpenCode, abychom byli na stejné vlně.

Můžu OpenCode používat bez OpenRouter?

Ano — OpenCode podporuje OpenAI, Anthropic, Google, Groq, lokální Ollama atd. Ale pro workshop budeme používat OpenRouter, protože ho nakonfiguroval Kuba a všichni budeme mít stejné prostředí.

Jak smažu OpenCode, když ho nebudu chtít

  • Mac (brew): brew uninstall opencode
  • Mac (curl): opencode uninstall nebo smaž ~/.opencode/
  • Windows (Scoop): scoop uninstall opencode
  • Windows (npm): npm uninstall -g opencode-ai

Auth klíč smažeš příkazem opencode auth logout nebo ručně smazáním ~/.local/share/opencode/auth.json (Mac) / %USERPROFILE%\AppData\Local\opencode\auth.json (Win).
