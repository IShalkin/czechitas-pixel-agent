Proč Copilot vs Claude Code

Na workshopu jste viděly skill v Claude Code — frontmatter name + description, agent si ho sám stáhne, když description sedí na váš dotaz. To je standard od Anthropic.

V GitHub Copilotu není úplně totéž, ale je tam koncepčně blízký mechanismus. Místo „skill" se to jmenuje prompt file. Stejný nápad: jeden Markdown soubor s instrukcemi, který si vyvoláš znamým způsobem (/jméno v chatu).

Anthropic / Claude Code

~/.claude/skills/sql-review/SKILL.md

Frontmatter: name + description

Auto-discovery: agent vybere podle description

Globální (sdílí mezi projekty)

GitHub Copilot

.github/prompts/sql-review.prompt.md

Frontmatter: mode + description + tools

Manual invoke: /sql-review v chatu

Per-projekt (žije v repu)

Bonus pro Copilot: prompt file můžeš commitnout do gitu — takže celý tým ho má sdílený, ne jen ty.

Tři druhy Copilot „instruktážních" souborů

.github/copilot-instructions.md — vždycky načteno (jako AGENTS.md). Pravidla projektu.

.github/instructions/*.instructions.md — načítá se podle applyTo patternu (např. jen pro **/*.sql).

.github/prompts/*.prompt.md — vyvoláš ručně přes /jméno. Tohle je nejbližší skillu.

0 · Co potřebuješ

  • VS Code (nebo VS Code Insiders) — minimum verze 1.97
  • GitHub Copilot rozšíření aktivní (přihlášená přes svůj GitHub účet)
  • GitHub Copilot Chat rozšíření
  • Vlastní git repo (i prázdné) — místní složka stačí

✓ Jak ověříš, že máš Copilot správně

V dolní liště VS Code uvidíš ikonu Copilota. Klik → otevře se Chat panel. Pokud nevidíš Chat panel, doinstaluj GitHub.copilot-chat z Marketplace.

Krok 1 Připrav repo a strukturu

V kořeni svého projektu vytvoř dvě složky:

# v terminálu, ve své projektové složce
mkdir -p .github/prompts
mkdir -p .github/instructions

Tečka před github je důležitá — Copilot prohledává jenom tuhle skrytou složku.

⚠ Pozor — VS Code Settings

Prompt files jsou ve VS Code zatím za přepínačem. Otevři Cmd/Ctrl + ,, vyhledej chat.promptFiles a zaškrtni. Bez toho VS Code prompt soubory neuvidí.

Krok 2 Napiš copilot-instructions.md

Tohle je tvůj AGENTS.md ekvivalent — pravidla projektu, která Copilot načte vždycky.

Vytvoř soubor .github/copilot-instructions.md:

# Pravidla projektu

## Stack
- Python 3.13, pandas, plotly
- Snowflake DB COURSES, schema SCH_TEROR
- Výstupy do `dist/` složky (HTML reporty)

## Konvence
- Read-only databáze. Žádné DROP / UPDATE bez schválení.
- Tabulky `_OLD` jsou archivy — nepoužívej.
- `COUNTRY_DIRTYDATA` je znečištěná kopie — místo ní použij `COUNTRY`.
- Hlavní fakta tabulka je `TEROR2`.

## Tón odpovědí
- Stručně, bez „rád ti pomohu".
- Když se neptám na vysvětlení, nevysvětluj.
- Czech komentáře v kódu, anglicky proměnné.

## Bezpečnost
- API klíče vždy z `.env`, nikdy v kódu.
- Necommituj `.env`, `secrets.json`, `dist/`.

Tohle Copilot načte při každém chatu, který se týká tohohle repa. Žádný frontmatter, jen markdown.

Test — funguje to?

Otevři Copilot Chat, zeptej se: „Jaké jsou pravidla tohoto projektu?" Copilot by měl shrnout, co je v copilot-instructions.md. Pokud řekne, že žádná pravidla nezná → soubor není na správném místě nebo není zapnutý preview flag.

Krok 3 Vytvoř první prompt file

Tohle je tvůj skill. Reusable recept na konkrétní úkol.

Vytvoř soubor .github/prompts/q-report.prompt.md:

---
mode: 'agent'
description: 'Vygeneruj brandovaný HTML report z dat. Použij naši paletu, layout, formátování čísel.'
tools: ['codebase', 'editFiles', 'runCommands']
---

# Q-Report Generator

Tvým úkolem je vyrobit HTML dashboard z poskytnutých dat.

## Layout (přesně tento pořádek)
1. Hero sekce — název reportu + datum
2. Executive summary — 3-5 bulletů
3. Tři grafy (Plotly, ne matplotlib)
4. Tabulka top 10 řádků
5. Footer s logem a poznámkou „Generováno {datum}"

## Brand
- Paleta: `#0a0e14` (pozadí), `#ff9c4a` (akcent), `#5bc0eb` (data)
- Font: Inter pro text, JetBrains Mono pro čísla
- Čísla v českém formátu: `1 234 567` (mezery, ne tečky)
- Logo z `assets/logo.svg` vlevo nahoře

## Pravidla
- Vždy se zeptej, jaký quartal/měsíc, pokud uživatel neřekl.
- Když data nemají sloupec, který bys čekal — neuhádej. Zeptej se.
- Výstupní soubor uložíš do `dist/q-report-{datum}.html`.
- Šablonu drž stejnou jako v předchozí verzi (`dist/q-report-Q1-2026.html` jako referenční).

## Po dokončení
- Stručně shrň, co jsi vygeneroval (3 řádky).
- Nech otevřený VS Code preview HTML souboru.

To je celý tvůj skill. Markdown s frontmatter na začátku.

PoleCo dělá
modeagent = Copilot může číst soubory, editovat, spouštět příkazy. ask = jen odpovídá. edit = navrhuje úpravy v souborech, které otevřeš.
descriptionCo prompt dělá. Zobrazí se v UI při výběru.
toolsKteré schopnosti smí použít. codebase = čte projekt, editFiles = mění soubory, runCommands = spouští příkazy v terminálu, fetch = HTTP, search = web search.

Krok 4 Otestuj v chatu

Otevři Copilot Chat (Ctrl/Cmd + Alt + I) a napiš:

/q-report

Copilot ti rozbalí menu — uvidíš svůj prompt v seznamu. Vyber, případně připoj data:

/q-report Vygeneruj report za druhé čtvrtletí, data jsou v `data/q2-2026.csv`.

Co se teď stane:

  1. Copilot načte q-report.prompt.md + copilot-instructions.md dohromady
  2. Přečte CSV (díky codebase tool)
  3. Vyrobí HTML soubor v dist/ (díky editFiles tool)
  4. V chatu shrne, co udělal

✓ Sigál, že to funguje

HTML soubor se zjeví v dist/, otevřeš ho v prohlížeči, vidíš svou paletu, čísla s mezerami, layout přesně podle promptu. To je ten „oooo" moment, který jsi viděla na workshopu.

Krok 5 Připoj MCP (volitelné)

Pokud chceš, aby tvůj skill chodil rovnou do databáze — místo CSV — připoj MCP server. V Copilotu se MCP konfiguruje v .vscode/mcp.json.

Příklad pro Snowflake (stejný setup, který jsi viděla s Tánou):

{
  "servers": {
    "snowflake": {
      "command": "uvx",
      "args": [
        "mcp-server-snowflake",
        "--account", "${input:account}",
        "--user", "${input:user}",
        "--warehouse", "COMPUTE_WH"
      ],
      "env": {
        "SNOWFLAKE_PASSWORD": "${input:password}"
      }
    }
  }
}

Po uložení Copilot zobrazí v Chatu nový set nástrojů (list_tables, describe_table, execute_query). Přidej je do svého skillu:

---
mode: 'agent'
tools: ['codebase', 'editFiles', 'runCommands', 'list_tables', 'describe_table', 'execute_query']
---

Teď tvůj skill umí tahat data přímo ze Snowflake a generovat HTML. Stejný workflow, který jsme dnes ukazovali na workshopu — jen ve tvém VS Code.

⚠ Klíče nikdy v souboru

${input:password} = VS Code se zeptá pokaždé. Necommituj .vscode/mcp.json s heslem v textu. Lepší: .env + ${env:SNOWFLAKE_PASSWORD}.

FIX Když něco nefunguje

SymptomCo s tím
/q-report není v menu Zapni chat.promptFiles v Settings. Restart VS Code. Zkontroluj, že soubor je v .github/prompts/ a má příponu .prompt.md.
Copilot říká „nemám pravidla" copilot-instructions.md musí být v .github/, ne v kořenu. Žádné podsložky.
Skill ignoruje brand barvy Frontmatter tools nesmí být moc úzký. Zkus přidat 'codebase', ať Copilot vidí copilot-instructions.md.
MCP server nestartuje Otevři výstupní panel „MCP" ve VS Code. Tam je log. Nejčastěji: chybný path k uvx nebo špatné heslo.
Copilot edituje špatné soubory Buď konkrétní v promptu: „uprav dist/q-report.html, nic jiného". Nebo zužitnost tools — vyhoď 'editFiles' a nech jen 'runCommands'.

Co dál Tvůj druhý skill

První skill jsi udělala. Teď přidej druhý — něco, co děláš opakovaně. Pár inspirací:

  • Code review checklist — Copilot ti řekne, jestli PR splňuje pravidla projektu
  • Slack zápis z porady — z přepisu vyrob 5 bulletů + action items
  • SQL optimizer — vezmi pomalý dotaz, navrhni indexy a EXPLAIN
  • README generator — z kódu projektu vyrob README s instalací a příklady
  • Email tone fix — vlož draft, dostaneš profesionální verzi v jednotném tónu

Pravidlo: když to děláš podruhé, patří to do skillu.

✓ Anthropic ekvivalent

Pokud později přejdeš na Claude Code (CLI od Anthropic) nebo OpenCode, převést prompt file na skill je triviální. Frontmatter mode/tools nahradíš za name/description, soubor přesuneš do ~/.claude/skills/<name>/SKILL.md. Tělo zůstane úplně stejné.
