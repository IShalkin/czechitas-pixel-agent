Speaker script — Report z přirozeného jazyka

Tučně = mluvený text. Kurzíva = režijní pokyn (co dělat rukama). Zelené karty = demo / interakce s holkami. Červené = fallback.

📊 Slide 01 0:00 → 1:30 ~1.5 min
Title — co dnes uděláme
Stůj rovně. Po Kubovi a Táně máš pozornost — neztrať ji dlouhým úvodem.
Dobrý večer. Já jsem zase Ilia. Včera jsme řešily pravidla — skill, markdown soubor, AGENTS.md. Před chvílí Tana ukázala data — Snowflake přes MCP. Teď to spojíme.
Cíl těchto padesáti minut: jeden český dotaz → HTML dashboard, který otevřete v prohlížeči. Žádné SQL, žádný kód. Pracujeme spolu — vy diktujete, agent dělá, já komentuju.
→ na slide 02.
🔁 Slide 02 1:30 → 7:00 ~5.5 min
Recap — kde jsme a co teď
Tahle slide má dva sloupce. Vlevo včera, vpravo dnes. Skill nás naučil jak. MCP dal agentovi k čemu sahat. Když to spojíme — z jednoho českého dotazu vyleze brandovaný report.
Ukazuj rukou na sloupce, když mluvíš.
A pozor — v reálných datech bývají pasti. Staré tabulky, dirty kopie, sentinely. Schválně sledujte čísla, která agent vytáhne. Něco vás dnes možná zkusí oklamat. Když to uvidíte, řekněte to nahlas. Já čekám.

⚠ Pokud žádná past nepřijde

Není to katastrofa. Pointa „nedůvěřuj reportu" platí i bez ní. Slide 05 (trap reveal) můžeš přeskočit nebo to já zinscenuju tím, že schválně se zeptám na COUNTRY_DIRTYDATA.

→ na slide 03.
🔧 Slide 03 7:00 → 12:00 ~5 min
Pipeline — co se za 3 minuty stane
Než pustím demo, ukážu z čeho je to udělané. Čtyři krabičky.
Postupně ukazuj na každou krabičku. Počítej k tomu prsty.
Jedna. Český prompt. To, co napíšete vy. Žádné SQL. Dvě. Skill. Markdown soubor, který říká agentovi jak ten report vyrobit. Tři. MCP. To, co Tana před chvílí nastavila. Agent pošle list_tables, describe_table, šestkrát execute_query. Čtyři. Dashboard.html. Self-contained, otevřu v prohlížeči.
A pod tím vidíte úryvek skillu. Třicet řádků markdownu. „Co fetchnout", „co odmítnout", „co výstupit". Stejný formát jako včera — jen jiný recept.
→ na slide 04. Tady začíná živá akce.
⚡ Slide 04 12:00 → 32:00 ~20 min · LIVE
Live demo — vy diktujete, agent dělá
Otevři terminál. Zvětši písmo (Cmd/Ctrl+). Spusť Claude Code. Mlč 5 sekund — ať si holky všimnou, že tam nic není.

FÁZE 1 · Vytáhneme skill před nimi (~3 min)

Než zadám prompt, ukážu jim, co skill je.

  • Otevři ~/.claude/skills/html-report/SKILL.md v editoru
  • Zvětši písmo
  • Ukaž frontmatter (name, description) — řekni „toto je kdy ho použít"
  • Ukaž tělo — sekce „What to fetch first", „Reject", „Output"
Tohle je celý skill. Ten markdown soubor. Třicet řádků. Žádný framework, žádná aplikace. Jen recept. „Když uživatel chce HTML report z dat, dělej toto, vyhni se tomuhle, výstup vrať takhle." Zavírám editor — stejný soubor agent uvidí, až se ho zeptám.
— PAUZA — 3 SEKUNDY

FÁZE 2 · Vy diktujete, já píšu (~12 min)

Otevři Claude Code chat. Otoč se na holky.

  • „Co vás zajímá z těch tabulek, co Tana ukázala?"
  • Sbírej 2–3 nápady. Zopakuj je nahlas (kotvení).
  • Sestav z toho prompt v reálném čase, mluvíc nahlas.
Takže — co byste chtěly z těch dat vidět? Nějaký report z Czechitas kurzů? Top 5 lektorek podle hodnocení? Vývoj počtu studentek za rok? Říkejte.
Sbírej odpovědi. Když je ticho, navrhni sama: „Co takhle top 10 nejnavštěvovanějších kurzů + grafy podle měsíců?"
Dobře. Takže napíšu agentovi: „Vygeneruj HTML report z tabulek ve Snowflake. Top 10 kurzů podle počtu studentek. Časová řada za posledních dvanáct měsíců. Pro junior analyst, který ta data vidí poprvé. Self-contained HTML."
Pošli prompt. Mlč. Nechej agenta pracovat.

FÁZE 3 · Komentář během práce (~5 min)

Když vidíš list_tables / describe_table: říkej nahlas co agent dělá. Nesmí to být ticho.

  • „Vidíte? Začal list_tables. To vynutil skill. Bez skillu by si vymyslel sloupce z hlavy."
  • „Sahá na describe_table. Ověřuje si, co tam vůbec je."
  • Když pošle SQL: „Tohle je read-only. Skill ho zakázal psát do databáze."
  • Když píše HTML: „Reálná čísla, žádné placeholdery. To zase vynucuje skill."

⚠ Pokud agent zatuhne / MCP padne

Nepanikuj. Řekni: „Tohle se dnes občas stává — síť, autorizace. Mám zálohu." → otevři dashboard.html z czechitas-pixel-agent / nebo přejdi na Stack Trace demo. Pointa zůstává.

🪤 Slide 05 32:00 → 38:00 ~6 min
Trap reveal — „počkejte, tohle nesedí"
Otevři vygenerovaný dashboard.html. Zvětši. Pauza 5 sekund — ať se holky podívají.
Dobře. Máme report. Vypadá to hezky. Ale.
PAUZA
Když ten report přinesete v pondělí na poradu — co by mělo zarazit? Sledujte čísla.

Pokud je v reportu COUNTRY_DIRTYDATA

Ukaž na číslo. „408 zemí. Kolik je na světě států? OSN má 193 + 2 pozorovatele. Kolik říká náš report? 408. Kde se vzala ta dvojnásobná hodnota?"

Ukaž na zdroj v kódu. „Z tabulky COUNTRY_DIRTYDATA. Duplikovaná. Agent mohl sáhnout na COUNTRY, ale šel po té špatné. Skill ho varoval — ale výsledný HTML to neopravil."

Pokud past v reportu není

Řekni: „Dnes to dopadlo dobře. Ale kdo garantuje, že to dopadne dobře zítra, na jiných datech?" Pointa stejná — agent může vybrat špatně, skill je nutná podmínka, ne dostatečná.

A tohle je rozdíl mezi „funguje" a „funguje pokaždé". Skill je silný, když funguje. Otázka, kterou si položíte v práci: jak víme, že funguje pokaždé?
Odpověď: evals. Automatický test, který říká „ano, agent ze skillu vyjel správný query, ano, vybral správnou tabulku, ano, čísla sedí". Ale to už je téma pro Kubu — on po mně dnes evals dělá.
→ na slide 06.
📦 Slide 06 38:00 → 45:00 ~7 min
Co si odnášíš — tři dema + domácí úkol
Než předám slovo Kubovi, dvě praktické věci.
Tři demo stránky jsou nahrané online. Pixel Agent — vizualizace toho, co jsme teď viděly. Stack Trace — pět vrstev kontextu jednoho dotazu. Skill Builder — ten samý soubor, jen postavený klikáním. Všechno běží v prohlížeči, žádný setup.
A domácí úkol — volitelný, ale stojí za to. Univerzální gajd „kam patří skill v Copilotu, Claude Code i OpenCode". Ten samý úkol — HTML report — ve třech harness'ech. Princip pochopíš jednou, použiješ kdekoliv.

Praktická poznámka

Většina z vás bude pokračovat v Copilotu (to, co Tana nastavila). Gajd je pro to napsaný — ale ukazuje i Claude Code variantu, abyste viděly, že je to stejný princip, jen jiná složka. Až někdy budete pracovat s jiným agentem, znáte to.

A tím dnes končíme. Dvě věci, co byste si měly odnést — skill je markdown soubor, ne framework, a nedůvěřujte výstupu, dokud ho nezměříte. To první vám usnadní práci. To druhé vám zachrání práci.
Předávám Kubovi. Děkuju.
Tlesk by měl přijít. Pokud ne — řekni „díky" a posaď se. Kuba převezme.

🚨 Fallback — když něco selže

Pokud Snowflake MCP padne

  • Neřeš to nahlas víc než 10 sekund. „Síť. Mám zálohu."
  • Otevři dashboard.html z czechitas-pixel-agent (předem nachystaný).
  • Komentuj, jako by ho právě vyrobil agent. Pointa jak skill řídí flow zůstává.
  • Slide 05 (trap reveal) udělej ručně — ukaž na něco v dashboardu, řekni „kdyby tohle bylo z _OLD tabulky, nevěděl bys to".

Pokud Claude Code zatuhne / token expiroval

  • Nikdy neztrácej více než 30 sekund na restart.
  • Plán B: Stack Trace demo — ishalkin.github.io/czechitas-stack-trace — ukáže pět vrstev jednoho dotazu staticky. Pointa stejná.
  • Plán C: otevři SKILL.md v editoru a vysvětli ho čtením. Říkej, co by agent měl udělat. Holky si představí.

Pokud holky nereagují / nediktují prompt

  • Nečekej víc než 10 sekund. Navrhni sama: „Co takhle top 10 kurzů s časovou řadou?"
  • Pokud někdo navrhne těžkou věc (machine learning, predikci) — pochval, ale řekni: „Skvělé, to je krok dva. Dnes uděláme krok jedna — zobrazení."
