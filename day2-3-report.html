Co skill agentovi vynucuje

# skill_html_report_generation.md (zkráceno)

## What to fetch first — vždy, před čímkoli
1. list_tables — co vůbec existuje?
2. describe_table na každou kandidátní tabulku
3. SELECT COUNT(*), SELECT * LIMIT 3 — sanity check

## Reject
- tabulky končící na _OLD, _LEGACY, _BACKUP, _V1
- "dirty" duplicates: COUNTRY vs COUNTRY_DIRTYDATA → preferuj COUNTRY

## Safety rules — never break these
- Read-only. Žádný INSERT / UPDATE / DELETE / DROP / TRUNCATE.
- Žádné vymyšlené sloupce — co není v describe, neexistuje.

Žádná magie. Skill je 30 řádků markdownu. Stejný formát jako včera.

// OpenCode chat · čistý kontext · Snowflake MCP enabled

Vygeneruj mi report o dataset COURSES.SCH_TEROR.
Audience: junior analyst v Czechitas, který tu databázi

otevřu v prohlížeči. Použij ten skill, co máme načtený.

Co budu komentovat nahlas

KdyCo řeknu
list_tables proběhne „Ten list_tables ho vynutil skill. Bez skillu by začal hádat sloupce z hlavy."
SQL queries letí „Každý query je konkrétní — TOP 10, GROUP BY. Žádné SELECT *. To je taky pravidlo ze skillu."
Sahá na COUNTRY i COUNTRY_DIRTYDATA „Skill ho nutí porovnat dva zdroje. Hned uvidíme, proč."
Generuje HTML „Píše soubor s reálnými čísly. Žádné placeholdery. To zase vynucuje skill — sekce What you'll produce."
Backup: pokud agent zatuhne nebo MCP padne, otevřu dashboard.html z czechitas-pixel-agent a komentuju jako live. Princip stejný.
🪤 TRAP REVEAL

Počkejte. Tohle číslo nesedí.

Otevřeme vygenerovaný dashboard.html. Pauza. Necháme všechny koukat 5 sekund. Pak:

Kolik je na světě států?

~195

OSN: 193 členů + 2 pozorovatelé. Realita.

Kolik říká náš report?

408

Z tabulky COUNTRY_DIRTYDATA. Duplikovaná. Ne COUNTRY.

To je rozdíl mezi „funguje" a „funguje pokaždé". Agent dnes vybral špatně. Skill na to upozornil v komentáři, ale výsledný HTML to neopravil. Nebo agent vybral správně — ale kdo garantuje, že to udělá zítra, na jiné databázi?

Předávací věta pro Kubu

„Skill je silný, když funguje. Otázka je: jak víme, že funguje pokaždé? Jak ověřit, že agent skutečně dělá to, co skill přikazuje? Odpověď: evals. Kuba."
