⚡ COLD OPEN · SAME AGENT, SAME PROMPT

Stejný agent. Stejný dotaz. Jiný výsledek.

Prompt: "Spočítej oběti terorismu po regionech od roku 2018."

❌ BEZ SKILLU

SELECT region_txt, year,
       COUNT(*), SUM(victims)
FROM teror2_old
WHERE year >= 2018;
  • tabulka _OLD — neaktuální
  • chybí GROUP BY → SQL chyba
  • žádný ORDER BY, žádný LIMIT
  • agent to klidně pošle do produkce

✅ SE SKILLEM sql-review

// agent ZASTAVÍ a řekne:
// "Tabulka _OLD je deprecated.
//  Použij TEROR2. Chybí GROUP BY.
//  Doplň ORDER BY victims DESC."

SELECT region_txt,
       SUM(victims) AS total
FROM teror2
WHERE year >= 2018
GROUP BY region_txt
ORDER BY total DESC;
  • kontroluje pravidla před spuštěním
  • vysvětlí proč, ne jen co
  • chytí chybu dřív, než se dostane do reportu
Rozdíl: jeden Markdown soubor v ~/.claude/skills/sql-review/SKILL.md.
📐 ANATOMY

Co je skill?

Jeden Markdown soubor s instrukcemi, které agent načte automaticky.

--- frontmatter --- name: sql-review co to je description: Use when user asks for SQL. kdy použít --- # SQL Review ## Pravidla tělo - Nikdy nepoužívej tabulky končící na _OLD. - Vždy doplň GROUP BY ke každé agregaci. - Když SUM/COUNT, doplň ORDER BY a LIMIT. ## Příklad - Před: SELECT ... FROM teror2_OLD ... - Po: SELECT ... FROM teror2 GROUP BY ...

📄 frontmatter

Říká agentovi kdy má skill načíst. description je spouštěč — pokud sedí na uživatelův dotaz, skill se aktivuje.

📜 tělo

Pravidla v lidské řeči. Žádné JSON, žádný kód. Agent je čte a aplikuje. Stejný formát jako AGENTS.md, jen cílený.
