# Czechitas workshop
# SQL analytics over Snowflake

## Stack
- Snowflake · DB COURSES
- Schema SCH_TEROR (terror data)

## Defaults
- Always read-only first
- Use TEROR2, never _OLD tables
- Czech comments OK

Co tam patří

  • Stack — jaký jazyk, jakou DB
  • Defaults — read-only? jaký tón?
  • Conventions — pojmenování, formát
  • Don't — žádné DROP, žádné UPDATE bez schválení
Pravidlo: všechno, co bys řekla nováčkovi v týmu první den, patří do AGENTS.md.
AGENTS.md = pravidla projektu (jak pracujeme tady). SKILL.md = pravidla úkolu (jak děláme SQL review). Doplňují se.
⚡ COLD OPEN · SAME AGENT, SAME PROMPT

Stejný agent. Stejný dotaz. Jiný výsledek.

Prompt: "Spočítej oběti terorismu po regionech od roku 2018."

Schéma COURSES.SCH_TEROR — má 3 tabulky: TEROR2, TEROR2_OLD, COUNTRY_DIRTYDATA. Agent neví, která je která.

❌ BEZ SKILLU — agent hádá

// vybere první tabulku co zní rozumně
SELECT region_txt, SUM(nkill) AS total
FROM teror2_old
WHERE iyear >= 2018
GROUP BY region_txt
ORDER BY total DESC;
  • SQL je syntakticky správné, vrátí čísla
  • ale _OLD je archív z roku 2017 → data jsou o 30 % nižší
  • agent neměl jak vědět — pošle graf do reportu
  • chyba se najde za týden, když si toho někdo všimne

✅ SE SKILLEM sql-review

// skill obsahuje firemní znalost:
// "Tabulky _OLD jsou archiv, nepoužívej."
// "COUNTRY_DIRTYDATA má znečištěná data."
// "Hlavní fakta tabulka je TEROR2."

SELECT region_txt, SUM(nkill) AS total
FROM teror2
WHERE iyear >= 2018
GROUP BY region_txt
ORDER BY total DESC;
  • agent ví, co neví — skill ho varuje
  • vybere správnou tabulku napoprvé
  • data sedí, report jde ven s důvěrou
Pointa: skill = firemní/projektová znalost, kterou agent nemůže vědět z trénovacích dat. Naming konvence, deprecated tabulky, dirty kopie. Jeden Markdown soubor ji předá.
📐 ANATOMY

Co je skill?

Jeden Markdown soubor s instrukcemi, které agent načte automaticky.

--- frontmatter --- name: sql-review co to je description: Use when user asks for SQL. kdy použít --- # SQL Review ## Pravidla tělo - Tabulky končící na _OLD jsou archivy — nepoužívej. - COUNTRY_DIRTYDATA je znečištěná kopie — místo ní použij COUNTRY. - Hlavní fakta tabulka je TEROR2 (ne TEROR1 ani TEROR_BACKUP). ## Příklad - Před: SELECT ... FROM teror2_OLD JOIN country_dirtydata ... - Po: SELECT ... FROM teror2 JOIN country ...

📄 frontmatter

Říká agentovi kdy má skill načíst. description je spouštěč — pokud sedí na uživatelův dotaz, skill se aktivuje.

📜 tělo

Pravidla v lidské řeči. Žádné JSON, žádný kód. Agent je čte a aplikuje. Stejný formát jako AGENTS.md, jen cílený.

🧠 MENTÁLNÍ MODEL

Prompt, config, skill — nejsou totéž.

Začátečnická chyba: všechno nazývat „prompt". V agentních systémech máme vrstvy.

VrstvaCo děláPříkladKdy
Prompt Co chci teď, jednorázově. "Zkontroluj tento SQL." ● dnes
Config Jak funguje prostředí. Dlouhodobá pravidla projektu. AGENTS.md — „Pracujeme read-only." ● dnes
Skill Jak dělat opakující se typ práce. SKILL.md — „SQL review postup." ● dnes
MCP Jaké nástroje má agent k dispozici. execute_query(), list_tables() ○ zítra
Evals Jak ověříme, že výstup dává smysl. „Chytil neexistující sloupce?" ○ zítra
Začátečnická chyba: všechno nazývat „prompt". V praxi: každá vrstva řeší jinou věc, a oddělené vrstvy = přehledný agent.
